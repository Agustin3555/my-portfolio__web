Creé una aplicación de escritorio para **coordinar y administrar proyectos de obras**, logrando **optimizar la coordinación interna** y **aumentar la eficiencia operativa en un 25%**. El sistema se diseñó tomando como referencia el modelo BIMBOX, incorporando funcionalidades clave a solicitud del cliente como la **asignación de responsables** y la **gestión de metadatos** en los archivos.

Para garantizar la **sincronización continua de archivos** entre los usuarios, se integró el sistema con la infraestructura existente de **Dropbox**. Con el objetivo de mantener una alineación de datos efectiva y asegurar un alto nivel de **seguridad e integridad**, estructuré la solución en dos versiones del programa:

- **Editor** (Coordinador): Administra la base de datos central como fuente de la verdad y genera/actualiza el archivo de sincronización.
- **Lector** (Profesionales a cargo): Consume el archivo de datos sincronizado en modo de solo lectura para la consulta segura de la información.

Dirigí este proyecto y tuve el gusto de colaborar con la desarrolladora [Daiana Del Grecco](https://daianadg-portfolio.vercel.app), cuya habilidad técnica y compromiso fueron clave para el éxito del desarrollo.
